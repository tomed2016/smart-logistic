# Domain Glossary

- **Bidón lleno**: unidad lista para despacho.
- **Bidón vacío**: unidad recuperada desde cliente.
- **Bidón retornable**: envase reutilizable sujeto a control.
- **Recurrencia**: regla de negocio que genera pedidos independientes a futuro.
- **Ocurrencia**: instancia puntual generada por una recurrencia.
- **Reprogramación**: cambio explícito de fecha con trazabilidad.
- **Reintento**: nuevo intento operativo tras una entrega fallida.
- **Planificación**: asignación versionada de pedidos a rutas y vehículos.
- **Ventana horaria**: rango permitido para atención al cliente.
- **Saldo**: deuda o crédito vigente del cliente.
